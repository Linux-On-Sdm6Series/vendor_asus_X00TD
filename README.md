# FM radio on Ubuntu Touch

The X00TD Cherokee backend requires `fm-bridge` and the Qualcomm FM libraries
in the Android vendor image. Before building the Lineage 16 vendor image, add
the bridge source to the Android source tree, for example:

```sh
git clone https://github.com/paulcarroty/violet-fm-bridge-2.git external/fm-bridge
git -C external/fm-bridge checkout a28866dffb4e3316174b4d5737b22bf9ba1963c9
```

Use this vendor tree at `vendor/asus/X00TD`. Its product makefile includes
`fm-bridge` and installs the FM libraries to the vendor image as well as their
original system-image locations. The makefile is generated by
`device/asus/X00TD/setup-makefiles.sh`; regenerating it will require these
changes to be reapplied.

After building and deploying the vendor image using the device port's normal
procedure, check that `/vendor/bin/fm-bridge`, `/vendor/lib64/fm_helium.so`,
and `/vendor/lib64/libfm-hci.so` exist. With wired headphones attached, open
the FM radio app and verify tuning and playback. The bridge and audio routing
have not yet been verified on X00TD hardware.
